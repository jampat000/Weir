## Design rules this session established — do not undo them

1. **`docs/design/content-language.md` rule 3 still holds**: no cards, no panels, no wells. Hierarchy
   is type and whitespace. When a page is too long, use the width, do not add boxes.
2. **`.mm-quiet-stack--columns`** puts groups in two columns above 1180px. Nested stacks inside it
   get `display: contents` so the columns balance the *groups*, not the component wrappers.
3. **`QuietDisclosure`** (`components/shared/quiet-section.tsx`) — a group that starts closed, for
   settings almost nobody changes. `<details>`, so it opens without JS and find-in-page reveals it.
   Its title is a real heading. It shows what is on inside it, and opens itself if anything is.
4. **One shape for a setting**: `.mm-field` + `.mm-field__label` + `.mm-field__hint`, and a control is
   one of three widths — `--mm-field-short` (a number or time), `--mm-field-medium` (a choice or short
   name), `--mm-field-wide` (a path or sentence). **This is only applied to Running and the retention
   fields.** Media managers, Alerts, Libraries and Rules still set their own widths — finishing that
   sweep is the main outstanding visual job.
5. **Every tab reads**: what this is → what you change → what you can do → what almost nobody opens.
6. A **dropdown looks like one**: accent chevron in a tinted well (`select.mm-input`), and the custom
   listbox triggers take the same well via `.mm-input--opens`. A field lifts off the page
   (`--mm-input-bg`); it used to be the same colour as the background.
7. **`html { scrollbar-gutter: stable; }`** (`weir-shell.css`) is why the page stops jumping sideways
   when a filter shortens it. James raised this about the first screen specifically. It looks like a
   stray line; it is not.
8. **The collapse button is parented outside `.mm-sidebar-inner` on purpose.** That element is the
   scroller (`overflow-y: auto`), and a button hanging off its edge gave the sidebar a horizontal
   scrollbar — "its a no no". It is absolutely positioned on `.mm-sidebar`, and `.mm-sidebar-inner`
   carries `overflow-x: clip`. Moving the button back inside re-creates the scrollbar.
9. **`mmActionButtonClass` has no `disabled` option.** A disabled button is styled by `disabled:` and
   `disabled:hover:` classes instead, so one call site cannot drift from another.
   `lib/ui/mm-control-roles.test.ts` fails if a `hover:` property loses its `disabled:hover:` pair.

- **Alerts are never sent.** Only `NoJobNotifications` is registered (`JobServices.cs:553`); the real
  `DispatchJobNotification` is never called. Only "Send test" delivers.
- **The work file sweep never runs.** It is queued hourly but has no `IJobHandler`.

saved but never read (only the per-library grid is enforced); Housekeeping's switches only take effect
