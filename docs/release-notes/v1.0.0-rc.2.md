# Weir v1.0.0-rc.2

Date: 2026-10-07

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/jampat000/Weir/issues).

This release candidate makes "Devices on my network" work on any network Windows is on, and fixes a misleading message about files waiting to start.

## What Changed

- **Network access works on every network.** On Windows, Weir still answers only on its own PC until you choose **Devices on my network** in **System › About** (or the tray's **Allow other devices on your network...**). When you do, its Windows Firewall rule now covers every network type: Domain, Private and **Public**. Windows marks many home networks Public, and the old rule skipped them, so the page said "Blocked by Windows Firewall" and other devices could not connect however often you tried. Weir is still behind its own sign-in, and first-time setup from another device still needs the one-time setup code.
- **Release candidates are published under their version tag only.** The Docker image for this release is `ghcr.io/jampat000/weir:1.0.0-rc.2`. `latest` stays where rc.1 left it and moves again with 1.0.0. The README, the Docker guides and `compose.yaml` name `1.0.0-rc.2`.

## Fixes And Stability

- **"Waiting for a free slot" is shown only when the slots really are full.** While Weir was scanning a library in the background, a file waiting for its workflow's schedule could be reported as "waiting for a free slot: 1 of 1 in use". Library scans and cleanups have their own slots and never take a file's, and the read-out now counts the same way Weir starts files.

## Upgrade Notes

- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top. Existing data is kept.
- **If you already chose Devices on my network and the page says "Blocked by Windows Firewall":** after updating, press **Try again** on that card. Windows may ask for administrator approval once. Weir then widens its existing rule to cover every network type.
- Docker: change the image to `ghcr.io/jampat000/weir:1.0.0-rc.2`, then `docker compose pull && docker compose up -d`. Docker is unaffected by the firewall change: your port mapping decides who can reach Weir.
