# Weir v1.0.0-rc.5

Date: 2026-10-08

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/jampat000/Weir/issues).

This release candidate lets Deluno check the folder each of Weir's workflows watches.

## What Changed

- **Deluno can check Weir's watched folders.** Weir's list of workflow folders now says which media-manager library each workflow was set up from, and whether that manager keeps its folders up to date. Deluno uses it to check that each library's downloads land where Weir is watching, instead of showing "Not reported by the processor" on its Health page.

## Upgrade Notes

- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top. Existing data is kept.
- Docker: change the image to `ghcr.io/jampat000/weir:1.0.0-rc.5`, then `docker compose pull && docker compose up -d`.

## Docker

- `ghcr.io/jampat000/weir:1.0.0-rc.5`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
