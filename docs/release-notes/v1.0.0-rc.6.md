# Weir v1.0.0-rc.6

Date: 2026-10-08

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/jampat000/Weir/issues).

This release candidate lets a media manager name its connection to Weir on its own.

## What Changed

- **Weir says what it is when a media manager asks.** Weir's answer to a media manager's first question now names the product as well as the machine, so Deluno shows the connection as "Weir on your-pc" without being told.

## Upgrade Notes

- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top. Existing data is kept.
- Docker: change the image to `ghcr.io/jampat000/weir:1.0.0-rc.6`, then `docker compose pull && docker compose up -d`.

## Docker

- `ghcr.io/jampat000/weir:1.0.0-rc.6`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
