# Weir v1.0.0-rc.7

Date: 2026-10-08

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/jampat000/Weir/issues).

This release candidate makes Weir live: every screen shows what is happening as it happens, with nothing to refresh.

## What Changed

- **Everything is live.** The Dashboard lanes, Activity, Library, System, Health, Logs, update status and the Setup, Connections and Settings lists all change the moment Weir's data changes. Nothing waits on a timer, and there is no need to reload or press Refresh to see new information.
  - A pause or resume shows straight away, and so does a timed pause running out.
  - A library check counts up the files it has looked at while it runs.
  - Health re-checks your workflows' folders by itself and turns red or green as soon as the answer changes. Each row says when Weir last looked.
  - Changes Deluno makes, such as a workflow it keeps in step, appear without a reload.
- **Weir says when it can't keep a screen live.** If the connection to Weir drops, a notice reads "Live updates paused: can't reach Weir. Reconnecting…", and the screen catches up by itself when it is back. After **Restart to apply**, the page recovers on its own.
- **If your session has ended**, Weir takes you to sign in instead of quietly showing old information.

## Fixes And Stability

- Connecting to a media manager or download client saved as `localhost` no longer waits about two seconds on Windows.
- When an address has more than one IP, Weir tries each in turn instead of giving up after the first.

## Upgrade Notes

- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top. Existing data is kept.
- Docker: change the image to `ghcr.io/jampat000/weir:1.0.0-rc.7`, then `docker compose pull && docker compose up -d`.

## Docker

- `ghcr.io/jampat000/weir:1.0.0-rc.7`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
