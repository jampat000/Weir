# Weir v1.0.0-rc.8

Date: 2026-10-08

> **Early days.** Weir is early, and it is in active, hard testing. Expect rough edges. If something is wrong or confusing, please report it on [GitHub issues](https://github.com/jampat000/Weir/issues).

This release candidate fixes what a clean install alongside Deluno turned up: folders Weir guessed, files it could not read, and messages people could not make sense of.

## What Changed

- **Weir never guesses a folder.** When Deluno doesn't say where a library's downloads arrive, Weir leaves that workflow's watched folder empty and says plainly what to set in Deluno. It no longer points a workflow at a folder every library shares, which stopped Weir's setup from finishing. A workflow that already holds such a folder is put right.
- **Setup explains itself.** If a download client saves everything to one folder, Weir says to give Movies and TV their own category folders, instead of offering nothing.
- **A file Weir can't read is never deleted, and never passed on.** Weir looks at it again over about an hour, as it does for a download that is still arriving. If it is still unreadable and hasn't changed, Weir refuses it before writing anything and leaves the original where it is.
- **Plain words instead of tool output.** Activity, Logs and what Weir tells Deluno now say what went wrong in a sentence, not raw ffmpeg text.
- **A later "imported" counts.** If Deluno first says it won't import a file and later imports it after all, Weir's record and Activity now say it was imported.
- **Linked workflows show only what can happen.** On a workflow linked to a media manager, "Delete only the rejected file" is shown as unavailable, because your media manager removes rejected downloads itself.

## Fixes And Stability

- Leaving a page while it is loading no longer puts an error in Logs.
- Weir only ever releases its own cleaned copy that a hand-off actually named, even when two answers from a media manager arrive at once.

## Upgrade Notes

- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top. Existing data is kept.
- Docker: change the image to `ghcr.io/jampat000/weir:1.0.0-rc.8`, then `docker compose pull && docker compose up -d`.

## Docker

- `ghcr.io/jampat000/weir:1.0.0-rc.8`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
