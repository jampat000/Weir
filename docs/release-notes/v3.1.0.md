# Weir v3.1.0

Date: 2026-09-20

This release makes **Files at once** mean what it says: pick a number from 1 to 10, and that many files are worked on together.

## What Changed

- **Files at once, 1 to 10.** In **Processing → Libraries → Processing, safety and records**, choose how many files Weir works on at the same time. It applies however a file arrived: handed over by a media manager or found in a watched folder. A burst of imports no longer has to queue behind one file at a time. The most you could choose before was 8.
- **One number, not three.** Until now three separate limits decided how many files really ran, and their defaults added up to one at a time however high you set Files at once:
  - Every library had its own limit of 1. A library now follows Files at once unless you give it a lower number of its own (**Edit library → Capacity and recovery → Files at once**), which is only for stopping one library from taking every slot.
  - A "resolution budget" quietly capped files found by a folder scan (two 1080p files, or one 4K file, with the default numbers). It is now a switch, **Also weigh files by resolution**, and it is off unless you were relying on it. Turn it on if your machine copes with several small files but only one 4K file.
- **Weir says what a waiting file is waiting for.** When files are queued, the overview and the setting itself name the one thing in the way, in plain words: "3 files are waiting for a free slot: 2 of 2 in use", "Movies runs 1 at once…", "processing is paused", and so on. Before, nothing on screen said which limit to change.

## Fixes And Stability

- A server started with fewer worker slots than Files at once asks for (the `WEIR_PROCESSING_WORKER_COUNT` environment variable) now says so beside the setting, instead of promising a number it cannot run. Most installs never set this variable and now start with 10 slots.

## Upgrade Notes

- **Nothing changes until you change it.** Upgrading does not alter how many files run today. If Files at once is 1, it stays 1. If you already run several at once, every limit you had is kept exactly as saved, including each library's own number and the resolution budget, which stays switched on for you.
- After upgrading, set **Files at once** to the number you want. More at once is mostly disk work, so a slow disk gains little past two or three.
- Each file is checked against **Minimum free output space** when it starts. With several large files running together, leave more headroom than you would for one.
- Weir updates its database automatically when it starts (one new setting). Databases from 3.1.0 can't be opened by 3.0.3 or earlier, so take a backup first if you want a way back.
- Windows: **Settings → Upgrade** or **Check for updates** in the tray, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
