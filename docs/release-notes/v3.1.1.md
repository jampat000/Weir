# Weir v3.1.1

Date: 2026-09-22

This release stops Weir opening a browser window every time it updates itself, and keeps the Files at once read-out answering while files are being processed.

## What Changed

- **Updates no longer open a browser window.** After an update, the Windows tray starts Weir again without opening it in your browser. Before, every automatic update opened a new window, and on a computer nobody sits at they piled up. Opening Weir yourself still does: from the Start menu, or by clicking its tray icon, which now takes one click instead of two. (#638)

## Fixes And Stability

- **The Files at once read-out answers while files are processing.** With several files being worked on together, the read-out under **Files at once** and in the overview caption could stop answering for about half a minute and then fail with "database is locked". It now reads without waiting for the files' own writes, so it answers at once. Processing itself was never affected. (#636)

## Upgrade Notes

- No database changes: 3.1.1 opens a 3.1.0 database as it is.
- The update *to* 3.1.1 is still applied by 3.1.0's updater, so that one restart may open a browser window. Updates after it will not.
- Windows: **Settings → Upgrade** or **Check for updates** in the tray, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
