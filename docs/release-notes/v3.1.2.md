# Weir v3.1.2

Date: 2026-09-22

This release fixes a rare fault in which two pieces of Weir's work could be handed the same database connection, failing a hand-off and possibly leaving the database locked for the work after it.

## Fixes And Stability

- **Two pieces of work never share a database connection.** When two opened the database at the same instant, the library Weir uses could hand both the same connection. One of them could then start its transaction on the other's behalf, and a hand-off or scan failed with "Safety level may not be changed inside a transaction". Opening a connection now happens one at a time for each database, which takes no measurable time. A connection that is ever found still inside someone's transaction is rolled back before it is used, and Weir notes it in the log. (#640)
- **A failed rollback no longer leaves the database locked.** If undoing an unfinished piece of work failed, its connection went back for reuse with the database still locked, and every piece of work after it waited and then failed. Such a connection is now closed instead of reused. (#640)

## Upgrade Notes

- No database changes: 3.1.2 opens a 3.1.1 database as it is.
- Windows: **Settings → Upgrade** or **Check for updates** in the tray, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
