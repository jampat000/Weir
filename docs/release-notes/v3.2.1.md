# Weir v3.2.1

Date: 2026-09-23

This release fixes a hand-off being reported as failed after Weir had finished it, and shows every file's full name so two releases of the same title can always be told apart.

## Fixes And Stability

- **A finished hand-off no longer reads "failed" because of an older one.** When a media manager handed Weir a release it had handed over before, a failure left by the earlier hand-off (a failed record for the release folder, or a hand-back that ran out of retries) was counted against the new one. Weir finished the file and told the manager "completed", then refused the manager's "imported" a minute later, saying the hand-off had failed. Deluno found this on the test rig with Tears of Steel. A failure from before a hand-off arrived now stays with the earlier hand-off; a failure during this one still counts.

## What Changed

- **Every file shows its full name.** Each card on Processing (Arriving, Waiting, Working, Handing back) and each Just finished row shows the file's own name under its title, so "The Long Tide (2024)" and its REPACK2 read as the two files they are. The title stays on one line so the lanes still line up; only the name wraps.
- **History and Library show names whole.** A long name is no longer cut short with "…".
- **Names wrap cleanly.** A long name breaks after a dot, dash or underscore, never mid-word, and the extension stays with the part before it.

## Upgrade Notes

- No database changes: 3.2.1 opens a 3.2.0 database as it is.
- Nothing a media manager reads has changed. Intake, the hand-off routes and the `handoff-outcome` capability are as in 3.2.0.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
