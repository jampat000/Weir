# Weir v3.2.10

Date: 2026-09-28

This release lets other devices on your network reach Weir on Windows, makes the Windows download smaller, and turns updates into small downloads of only what changed.

## What's New

- **Other devices on your network can reach Weir on Windows.** Installing Weir now asks once, with one Windows admin prompt, whether to allow other devices on your network to reach it. Saying yes adds one Windows Firewall rule for Weir's server, on home and work networks (Windows' Private and Domain networks) only, never on public Wi-Fi. It also clears any block Windows added earlier, for example if its own prompt was cancelled. The rule stays through updates and is removed when Weir is uninstalled with administrator rights.
  - If the prompt was skipped or refused, choose **Allow other devices on your network…** from the Weir tray icon.
  - **System › About** now says whether other devices can reach Weir, and how to fix it if not.
  - Installing from another program: `--silent` never shows the prompt. Add `--allow-lan` when starting Weir from a program that already runs as administrator, and the rule is set up without asking. See "Installing Weir from another program" in the Windows install docs.
- **Smaller Windows download.** The installer is 177 MB instead of 223 MB, and Weir takes about 386 MB on disk instead of 491 MB. It uses the shared build of the same FFmpeg version, and leaves out framework files for languages Weir doesn't use.
- **Faster updates.** Updates now download only what changed since your installed version, and fall back to the full download when needed. The first update to 3.2.10 is larger than usual because it also replaces FFmpeg.
- **Source code and licence in System › About.** Each release also carries the exact source of the FFmpeg and MKVToolNix versions bundled with the Windows package.

## Upgrade Notes

- No database changes: 3.2.10 opens a 3.2.9 database as it is.
- Nothing a media manager reads has changed.
- Updating an existing install doesn't show the network prompt, because it only appears on a fresh install. Use **Allow other devices on your network…** in the tray menu if other devices can't reach Weir.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`. Nothing about the firewall changes for Docker; publish the port as usual.
