# Weir v3.2.11

Date: 2026-09-29

This release makes Weir on Windows reachable only from the PC it runs on until you allow other devices on your network.

## What Changed

- **Only this PC can reach Weir until you allow your network.** Weir on Windows used to listen on every network connection even when nothing had allowed other devices in. It now listens only on the PC itself until LAN access is turned on:
  - you say yes to "Allow Weir on your network?" when installing;
  - you choose **Allow other devices on your network…** from the Weir tray icon;
  - or an installer starts Weir with `--allow-lan`.
- **Turn it back off** with **Only allow this PC** in the tray menu. Changing it restarts Weir's server, and the tray says so.
- **System › About › Network access** now says whether only this PC, or other devices on your network too, can reach Weir, and which tray item changes it.

## Fixes And Stability

- Running Weir's own test suite on Windows no longer pops a Windows Terminal error window.
- Releases are built and published faster, with each version tested once.

## Upgrade Notes

- **Existing installs keep the reach they have.** If Windows already lets Weir's server in, through Weir's own firewall rule or an earlier "Allow" on Windows' own prompt, Weir keeps listening on your network after the update. Otherwise it becomes reachable from this PC only; use **Allow other devices on your network…** in the tray to open it up.
- **Installing from another program:** `--allow-lan` now always turns LAN access on. When the installer runs as administrator it also adds the firewall rule; without administrator rights Weir still listens on the network, logs that the rule could not be added, and exits 0. Without `--allow-lan`, Weir is reachable from this PC only.
- No database changes: 3.2.11 opens a 3.2.10 database as it is.
- Docker is unchanged: the container listens on its port as before; publish it as usual.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top. Existing data is kept.
- Docker: `docker compose pull && docker compose up -d`.
