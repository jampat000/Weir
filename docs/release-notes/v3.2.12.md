# Weir v3.2.12

Date: 2026-09-29

This is a maintenance release: nothing changes in how Weir works for you. It's built with a quicker release process.

## What Changed

- Nothing you use has changed. Weir's own release process now tests each version once and downloads faster, so fixes can reach you sooner.

## Fixes And Stability

- The Docker and install documentation now shows pinned image versions as `X.Y.Z`, with a pointer to the releases page, instead of a version number that went out of date with every release.

## Upgrade Notes

- No database changes: 3.2.12 opens a 3.2.11 database as it is.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top. Existing data is kept. The update from 3.2.11 is small.
- Docker: `docker compose pull && docker compose up -d`.

## Docker

- `ghcr.io/jampat000/weir:3.2.12`
- `ghcr.io/jampat000/weir:latest`
- Images are published for `linux/amd64` and `linux/arm64`, and run the .NET build of the Weir server.
