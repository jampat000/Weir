# Weir v3.2.14

Date: 2026-09-30

qBittorrent 5.x stays connected, and a downloaded update no longer interrupts a running Weir.

## Fixes And Stability

- **qBittorrent 5.x stays connected.** 3.2.13 connected once, then reported the password as refused on every later check. Weir now logs in fresh each time and accepts qBittorrent 5.x's answer. Connections no longer share session cookies with each other.
- **Updates install when you quit or restart, as the notice says.** Before, a downloaded update was forced in about a minute later, stopping Weir mid-work.
  - **Quit, Restart to update, or System › About › Restart to apply:** Weir first stops cleanly, then installs the update.
  - **Windows shut down before you quit:** the update installs the next time Weir starts, before it begins work.
- The update settings on System › About now describe what each mode really does.

## Upgrade Notes

- No database changes: 3.2.14 opens a 3.2.13 database as it is.
- Windows: this update is installed by 3.2.13's own updater, so Weir may restart itself about a minute after downloading it, as before. From 3.2.14 on, updates wait for you to quit or restart. `Weir-win-Setup.exe` over the top also works; existing data is kept.
- Docker: `docker compose pull && docker compose up -d`.
