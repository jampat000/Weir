# Weir v3.2.16

Date: 2026-10-01

Settings are reorganised so every setting has one home. Performance is only about speed. Each workflow owns the rules for its new downloads, and the Library page owns your existing collection. Automatic updates install by themselves once Weir is idle, and a group of fixes stops Weir marking work done that wasn't.

## What Changed

- **Performance is only about speed:** Files at once, and weighing files by resolution. Everything else moved to where it belongs, and nothing is set in two places any more.
- **Each workflow owns its new downloads:**
  - **When a file is ready:** one wait, "A new file is ready once it hasn't changed for N seconds". It replaces the three separate waits.
  - **Which files:** the minimum size sits with the other file filters.
  - **Output:** "Keep at least N GB free on the drive this workflow writes to", checked on every write that workflow makes.
  - **Most files at once from this workflow:** shown as its share of Weir's total, and never more than the total.
  - **When a file fails:** the retry settings and what happens when retries run out, all in one section. "Maximum automatic attempts" now means exactly that number, and a file Weir gives up on always reads **Failed**, with the reason.
- **The Library page holds your existing collection.** A **Library setup** panel has the folders, the rules profile (the workflow's by default, or its own), the daily clean, the seeding option and keeping originals.
- **Your playback devices** (Direct Play) moved to Settings › Rules.
- **File history** is kept for as long as Weir knows the file, then for a number of days after it's gone. Set it on the History page.
- **Library cleaning** uses the workflow's "Writes files with" choice.
- **"Process all again"** on History re-checks every rejected file with your current rules.
- **Connections can have an optional nickname**, shown beside the machine name, e.g. "Radarr on nas · 4K".
- **Automatic updates install by themselves once Weir has been idle for 5 minutes.** Weir stops cleanly first, installs, and comes back. Download only and Notify only never install by themselves.

## Fixes And Stability

- **A full output drive no longer marks files as done.** They wait, with a plain reason, and carry on once there is room. A file under the minimum size is recorded as skipped.
- **Saving a workflow now really saves "Writes files with".** Before, it was quietly dropped, including when you saved hours on the Schedule tab.
- **A minimum size a workflow didn't set can no longer delete files.**
- **The greyed-out hardware settings are gone.** They could still affect processing although they were locked.
- **Retries happen soon after their wait,** not at the next scheduled scan.
- **Removed Cleanup's "Downloads of failed files" job.** It could not do what it said. History's remove dialog and "When retries run out" handle failed downloads.
- **The Folder chain checks only the download clients a workflow actually uses.** It says "not verified", rather than "Needs a fix", for a client folder Weir can't see from this machine.
- **A "Something else" media manager** can be added without an address again.
- **Windows:**
  - uninstalling, or installing over a running Weir, stops the server cleanly;
  - Restart to update is silent;
  - a waiting update is only ever installed by Weir's own start-up step.
- **qBittorrent:** a bare empty 200 answer to a login is no longer taken as success.
- **Docs site:** the dependencies with security advisories are updated.

## Upgrade Notes

- **Your settings are kept.** The database upgrades automatically, and each workflow keeps the values it used before, written into the workflow itself:
  - **Wait:** the longest of its old waits, so no file is picked up sooner.
  - **Minimum size:** the size it really used.
  - **Free space:** the free space Performance had.
- Older backups restore by the same rules.
- Files already held "after repeated failures" become Failed, with their reason.
- Some settings were removed or moved: Performance's wait, minimum size, free space and half-written copy; and the workflow's hardware and "hold every new file" settings. Anything that still sends them is accepted, and the values are ignored.
- **Windows:** this update is installed the new way: when Weir is idle in Automatic mode, when you quit or restart, or at the next start. Or install `Weir-win-Setup.exe` over the top; existing data is kept.
- **Docker:** `docker compose pull && docker compose up -d`.
