# Weir v3.2.2

Date: 2026-09-23

This release keeps the Processing screen still when you switch views, and makes History say plainly what Weir kept and removed from each file.

## What Changed

- **The figures bar on Processing no longer changes size.** Switching to a view with nothing handed back used to drop the "Last 2 hours" chart and its line of counts, and the numbers beside it changed width with every view, so the whole bar and everything under it shifted. The chart keeps its place (empty when there is nothing to show), the counts stay on one line, and today's two figures keep their width.

- **History shows what was kept and removed at a glance.** A file's tracks open with a heading that counts them ("Tracks · 3 kept · 2 removed"). Each track reads in full with a green Kept or red Removed label and a matching edge, and a removed track says why underneath.
- **History always shows Before, After and Saved.** A file Weir handed back unchanged shows the same size after and 0 B saved, instead of leaving the sizes out; a file Weir has not written a copy of shows its size and says so.

## Upgrade Notes

- No database changes: 3.2.2 opens a 3.2.1 database as it is.
- Nothing a media manager reads has changed.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
