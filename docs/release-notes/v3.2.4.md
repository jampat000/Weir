# Weir v3.2.4

Date: 2026-09-23

This release makes 3.2.3's fix work for libraries whose watched-folder scan is off.

## Fixes And Stability

- **Gone files are cleared even when a library never scans.** 3.2.3 made Weir forget a file that has left its watched folder, including one a media manager handed over, but only as part of a watched-folder scan. A library fed by a media manager's hand-offs often has its periodic scan off, so its gone files stayed listed. A new timer runs the same rule every five minutes for each library whose watched folder can be read, whether or not that library scans. It only forgets; it never queues work, so it cannot pick up a stray file a scan would have processed. A library whose watched folder cannot be read is skipped, so an unmounted share never empties the list.

## Upgrade Notes

- No database changes: 3.2.4 opens a 3.2.3 database as it is.
- Nothing a media manager reads has changed.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
