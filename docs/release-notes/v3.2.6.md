# Weir v3.2.6

Date: 2026-09-25

This release keeps Weir live while its browser tab is in the background, so coming back to it shows what is true now instead of catching up in front of you.

## Fixes And Stability

- **Weir stays live in a background tab.** Weir used to stop its live updates whenever you switched to another browser tab, and catch up when you came back: lists refreshed and progress jumped as you watched. The live connection now stays open. Activity keeps each screen's data up to date in the background, and live progress, which changes every second, is kept while the tab is hidden and drawn once when you return. Nothing is replayed.

## Upgrade Notes

- No database changes: 3.2.6 opens a 3.2.5 database as it is.
- Nothing a media manager reads has changed.
- Each open Weir tab now keeps one live connection to the server, including tabs in the background. Weir sends at most one progress update a second, plus an occasional keep-alive.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
