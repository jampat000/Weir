# Weir v3.2.7

Date: 2026-09-26

This release asks what to do with a failed or rejected download when you remove it from History, fixes two Processing screen bugs, and lets another program install Weir on Windows without hanging.

## What's New

- **Removing a failed or rejected title asks what to do with its download.** When the title's file is still in the watched folder, History asks:
  - **Delete the download and ask for another copy.** The media manager it came from (Sonarr, Radarr or Deluno) removes it, blocks that release and searches again. With Weir on its own, Weir deletes that one file.
  - **Keep the file, but don't process it again.** Weir leaves it until it changes, and the media manager is told it won't be imported.
  - **Try it again.**
  - **Just remove it from the list.**

  Before deleting or keeping anything, Weir checks the file is still the one that failed. A different download that has since landed under the same name is never touched. Weir also refuses any file reached through a link out of the watched folder. Every choice, and what each media manager was told, is recorded in Activity.
- **Kept files are listed in History.** A new **Kept** group lists the files you chose to keep, with **Process again** to change your mind.

## Fixes

- **Titles no longer disappear from Processing while they are being worked on.** The Working area now loads every title in progress itself, instead of reading them from a list of the 200 most recently seen files, where a busy watched folder could push a running title off the screen.
- **Titles you remove from History no longer linger on Processing.** They disappear from the alert and from "Just finished". Weir's running totals, such as files processed and space saved, and the full log in System › Logs are unchanged.
- **Weir's Windows installer can be run by another program.** `Weir-win-Setup.exe --silent` installs and exits with a success or failure code within seconds, and `Weir.exe --port <port> --silent` starts Weir with no windows or prompts. Weir no longer holds on to the output of the program that started it, which could keep an installer waiting for ever. See "Installing Weir from another program" in the Windows install docs.
- **Automatic rejects refuse a file reached through a link.** The same link check now protects the automatic reject step when it deletes a rejected download.

## Upgrade Notes

- **This release changes the database.** Migrations add the kept-files list, and the size and modified time of a file when its title fails or is rejected. A 3.2.7 database cannot be opened by 3.2.6 or earlier.
- **Titles that failed before 3.2.7 have no recorded size and modified time.** When you remove one, the dialog shows its file's name, size and modified time for you to confirm before Weir deletes or keeps it.
- **Installing from another program:** use `--silent`, as above. The earlier documented `Weir-win-Setup.exe -- --port 9347` waited for a person at the desktop.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
