# Weir v3.2.9

Date: 2026-09-27

This release makes Weir stop using its database the moment the database file is gone, instead of carrying on with a copy that no longer exists on disk.

## Fixes

- **A missing database is reported, not silently used.** On Linux, including the Docker image, a database file that was deleted or replaced by a folder while Weir was running could still be read and written through connections Weir already had open. Pages kept answering normally, but any change they made could not be saved to the real file. Weir now checks that the database file is still there each time it uses a connection. If it has gone, Weir drops those connections and reports the database as unavailable, the same way it does when the database cannot be opened.

## Maintenance

- The web app is built with Node 24 everywhere, both in the Docker image and in the checks run on every change, so what is tested is what ships.
- Dependency updates to the web app's libraries and to the build and security-scanning tools.

## Upgrade Notes

- No database changes: 3.2.9 opens a 3.2.8 database as it is.
- Nothing a media manager reads has changed.
- Windows: **Check for updates** in the tray or **System › About**, or install `Weir-win-Setup.exe` over the top.
- Docker: `docker compose pull && docker compose up -d`.
